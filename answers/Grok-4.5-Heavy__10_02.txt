**RACI Matrix for AtlasRemit Cross-Border Payment Process**

| Task | Transaction Analyst | Regulatory Liaison | IT Support |
|------|---------------------|--------------------|------------|
| Receive the customer’s transfer instruction and log it in the system | R, A | | |
| Screen the payment against the sanctions list | R, A | | |
| Perform the KYC Review on both sender and beneficiary | | R, A | |
| Approve high-risk transactions | I | R, A | |
| Release the payment | R, A | I | I |
| Ensure the SWIFT message is sent | I | | R, A |
| Archive the case file | | I | R, A |

**Legend**  
- **R** = Responsible (performs the work)  
- **A** = Accountable (owns the outcome; one A per task)  
- **C** = Consulted (none required by the process)  
- **I** = Informed
