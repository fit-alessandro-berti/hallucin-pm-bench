To meet the 48-hour SLA for reaching "Triage Claim", add an intermediateCatchEvent with a timerEventDefinition after the "Check Completeness" task (Task_Check). Set the timeDefinition to PT48H. Connect Task_Check to this new timer event. Add a new sequenceFlow from the timer to Task_Triage. This way, if 48 hours elapse after Task_Check, the process will automatically route to Task_Triage, skipping any wait for missing documents. The timer event acts as an "escalation" path to ensure the SLA is met. Existing logic for complete documents going straight to triage is preserved via the gateway (GW_Docs).
