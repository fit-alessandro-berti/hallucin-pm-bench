Here is the RACI table for the AtlasRemit payment process, using the mandated vocabulary:

| Activity                                   | Transaction Analyst | Regulatory Liaison | IT Support |
|--------------------------------------------|---------------------|-------------------|------------|
| Log customer transfer instruction          | R                   | I                 |            |
| Screen payment against sanctions list      | R                   |                   |            |
| Perform KYC Review on sender & beneficiary |                     | R                 |            | 
| Approve high-risk flagged transactions     |                     | R                 | I          |
| Release approved payment                   | R                   |                   | C          |
| Ensure SWIFT message is sent               |                     |                   | R          |
| Archive completed case file                |                     | I                 | R          |

R = Responsible, A = Accountable, C = Consulted, I = Informed

Notes:
- "Transaction Analyst" is used instead of "Payment Clerk" 
- "KYC Review" is used instead of "Customer Due Diligence"
- "Regulatory Liaison" is used instead of "Compliance Officer"
- Assumed the Regulatory Liaison is Accountable for the overall process, though this is not explicitly stated in the source
