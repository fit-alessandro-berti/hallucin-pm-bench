Here is my analysis of the Petri net PN-8:

**Question 1:** No, in any reachable marking it is not possible for transition T5 to fire before transition T3.

**Question 2:** No such firing sequence exists because:
1) T5 requires a token in both P2 and P5 to fire (it is a synchronizing join). 
2) The only way to get a token into P5 is by firing T4.
3) T4 requires a token in P4, which can only be produced by either T3 or T7 firing.
4) Both T3 and T7 occur after the AND-split at T1 that puts a token into P2.
Therefore, it's impossible to have a token in P5 without first firing T3 to consume the token in P2. So T5 cannot fire before T3 in any possible sequence.
